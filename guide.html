28JoursBox in 2 minutes

28JoursBox connects three kinds of devices around one shared band folder:

  • The server PC: a Windows PC belonging to the band that keeps all the files, runs the music analyses (at night) and stays on. Only one person installs it, and that person becomes the administrator.
  • The members' PCs: everyone gets a 28JoursBox folder on their Desktop that syncs with the server all by itself.
  • Phones (and any browser): nothing to install. Open the invitation link and you'll find all the files, the advanced player, the recorder…
🏠

Everything stays at home. Files, versions, takes, analyses and separated tracks are stored on the server PC's drive, not in a data center; the AI processing runs on that PC, at night. The flip side: backups are the band's job (see Back up). Why this choice?

Nickname and group password

There are no personal accounts with passwords. Each member picks a nickname, and a single password covers the whole band. It's already built into the invitation link, so in practice you never have to type it.

⚠️

Always use the same nickname on all your devices, and never use another member's: a nickname that already exists opens that member's session (capitals don't matter, "Marc" = "marc"). A new nickname creates a new member.

How to read this guide

  • Button and menu names are written as they appear in the app: Advanced player.
  • admin marks what only the band's administrator can do. On any device other than the server PC, you first need to unlock administration with the administrator password.
  • "Tap" is for the phone; on a PC, it's a click. "Long press": keep your finger down for about half a second.
  • A file's ⋯ menu opens with the ⋯ button on its row, or with a right-click on a PC. A long press on the row starts selecting several files.

Installing

The server PC (just once)

This is for the person who manages the band, on the PC that will keep the files. First check the system requirements.

  1. Download and run 28JoursBox-Serveur-Setup.msi (Download page) and accept the Windows administrator prompt. The MSI installs the "28JoursBox Server" Windows service, which starts with the PC, even when nobody is signed in.
  2. When the installation finishes, the Serveur 28JoursBox installé (28JoursBox server installed) notification appears and the 28JoursBox icon shows up next to the clock. Click the notification or the icon, then Tableau de bord (Dashboard) (or right-click the icon › Ouvrir le tableau de bord (Open the dashboard)).
  3. The Setup page (First setup) asks for the Group name and Your nickname: you become the band's administrator. Click Create the group.
  4. The The group is ready page shows the group password and the invitation link: send the link to the members, then click Continue to the files. You can find the link anytime in Invite someone.

The server PC's icon (next to the clock): a click opens its panel (Tableau de bord (Dashboard), État du serveur… (Server status…)); right-click offers Ouvrir 28JoursBox (Open 28JoursBox), Ouvrir le tableau de bord (Open the dashboard), Synchroniser aussi des fichiers sur ce PC… (Also sync files on this PC…) and Quitter (le serveur continue de tourner) (Quit (the server keeps running)). By default, the server PC has no synced 28JoursBox folder: choose Synchroniser aussi des fichiers sur ce PC… if you also want to work on this PC (the members' setup wizard opens, and the full PC app with its Préférences (Preferences) becomes available).

What gets set up: the Windows service, a firewall rule (Private network only), and the data in C:\ProgramData\28JoursBox.

💡

To keep the server reachable: turn off sleep when plugged in (Windows Settings › System › Power), use a network cable, and make sure the Windows network is set to the Private profile.

Access from outside (4G): Tailscale

Out of the box, the server can only be reached from the home Wi-Fi. There are two solutions, which you can combine: Tailscale, the simplest (nothing to set up on the router), and direct access, which is faster. Members' PCs automatically pick the fastest route that responds: local network, direct access, then Tailscale. With Tailscale, only the server PC installs anything; phones and other PCs install nothing. The diagram of how it works and the detailed step-by-step (including router by router) are on the Access from outside page.

  1. On the server PC, click the icon next to the clock › État du serveur… (Server status…) (on a PC that also syncs files: the panel's ⚙ gear › État du serveur…), Accès extérieur (Outside access) row › Régler… (Set up…). The Accès depuis l'extérieur (4G) (Access from outside (4G)) window opens. Click Installer Tailscale (Install Tailscale): the Tailscale download page opens; install it and sign in to Tailscale.
  2. Come back and click J'ai installé Tailscale, vérifier (I installed Tailscale, check) (or Vérifier à nouveau (Check again) if Tailscale wasn't connected yet).
  3. Click Activer l'accès extérieur (Turn on outside access). The first time, a Tailscale page opens: allow Funnel, then come back. Accept the administrator prompt.
  4. Result: "Accès extérieur activé : https://<pc>.<nom>.ts.net" (Outside access turned on). The invitation link now uses this address. At home, PCs keep going through the local network (faster for big WAV files).

The server PC checks the publication every 5 minutes and restores it if needed; if it stays down, the icon turns orange and the Accès extérieur interrompu (Outside access interrupted) notification appears. If you rename the machine in Tailscale, a Nouvelle adresse du serveur (New server address) notification appears: click it to apply it. Alternatives for advanced users: Cloudflare Tunnel, or port forwarding on the router with a proxy (Caddy), by setting PublicUrl in server.json.

Direct access (faster, without Tailscale) admin

Tailscale's relays are often limited to a few MB/s. With direct access, members connect straight to the server PC's router: much faster for big syncs and for playing a WAV on your phone. Tailscale stays as a backup, and direct access can be turned on or off at any time.

🧭

Detailed step-by-step, with the exact menus of the Orange, SFR, Bouygues and Free routers, how to give the server PC a fixed address and what to do if it doesn't work: Direct access step by step and Router by router.

  1. On duckdns.org (free): sign in (with a Google account, for example), reserve a name (e.g. "myband") and copy the token shown at the top of the page.
  2. On the router (Livebox: http://192.168.1.1, Network menu): under Baux DHCP statiques (static DHCP leases), always give the server PC the same address.
  3. Still on the router, NAT/PAT: forward port 8443 (TCP) to the server PC's address, port 8443. (Use 443 only if the router allows it: the address then shows no port.)
  4. In 28JoursBox: Settings › Server › Fast access through your router, fill in Name chosen on duckdns.org, duckdns.org account code and Port open on the router, check Turn on direct access, then Save. The HTTPS certificate (Let's Encrypt, free) is obtained in one to two minutes, then renews itself.
  5. Test it on a phone on 4G (Wi-Fi off) by opening the fast address shown, or tap Check now.

The card shows the status ("On: members' PCs use direct access"), the router address that was checked and the certificate's expiry date. Members' PCs follow along by themselves, with nothing to do. Phones keep the address of the installed app; listening and downloads go through direct access when it responds, falling back to Tailscale automatically.

⚠️

A VPN running on the server PC can block direct access. Opening a port on the router exposes the server to the Internet: it's protected by HTTPS and by the group password; keep Windows up to date. By turning it on, you accept the Let's Encrypt terms of use.

  2. Run the downloaded file. The wizard opens and finds the band by itself thanks to the copied link ("✓ Groupe …" box). Otherwise, paste the link into Lien d'invitation (Invitation link). No link? Pas de lien ? Saisir l'adresse et le mot de passe (No link? Enter the address and password).
  3. Choose Votre pseudo (Your nickname), then C'est parti (Let's go).
  4. A single page then brings together the folder location, the space gauge (at the very top, as soon as the space needed is known) and the choice of folders to keep on this PC (only the first folder is ticked at first; the Tout sélectionner (Select all) box ticks everything). The gauge compares your selection with the disk space (keeping 10% free): green, orange, or red if it doesn't fit; another drive is suggested if the one you picked doesn't have room. The ‹ Retour (‹ Back) button goes back to the link and nickname page. Confirm with Synchroniser ces dossiers (Sync these folders).

LibreOffice (previewing Office documents)

To view Word, Excel and PowerPoint files (and OpenDocument) on phones and in the browser, install LibreOffice (free) on the server PC only, in the default folder it suggests (C:\Program Files\LibreOffice). It's detected automatically, with no restart. Members' PCs and phones don't need it.

  • The first time a document is opened, the server converts it to PDF ("Preparing the preview…", 3 minutes at most), then keeps it: later openings are instant. New documents are also prepared at night.
  • Without LibreOffice, the app shows "Preview unavailable: LibreOffice is not installed on the server." with a Download button. Everything else works.
  • Installed somewhere else? Enter the path to soffice.exe in LibreOfficePath (server.json).
  • To check that it's detected: Settings › Server › Server status › Tools, Document preview (LibreOffice) row (administrator).

Updates and uninstalling

  • Members' PCs: the app checks with the server 1 minute after startup, then every 30 minutes and as soon as the server is reachable again (after its own update). When a new version is ready, a blue dot appears on the icon, the tooltip says so ("Version … · mise à jour X disponible", update X available) and a Mise à jour disponible (Update available) notification appears. Install it with Mettre à jour (Update), in the panel's banner or in Préférences (Preferences) › Général (General). Rechercher une mise à jour (Check for an update), in the panel's ⚙ gear or in Preferences, checks right away. Syncing stops for a minute during the installation, then 28JoursBox restarts by itself. A failed update is reported in the server log, with the PC's name. Updates are signed: a PC refuses any update that doesn't come from 28JoursBox, and never goes back to an older version.
  • Server PC admin: the server checks once a day whether a new public version exists. The server PC then shows the Mise à jour du serveur (Server update) notification (a click opens the window) and, in its panel, the banner "Nouvelle version X disponible (vous avez Y)" (New version X available (you have Y)) with Voir la mise à jour… (See the update…). The Mise à jour du serveur window offers Télécharger et installer (Download and install), Rechercher de nouveau (Check again) and Page de la version (Release page). The installer is signed and checked before installation; expect about a minute without access for the members. Another way: État du serveur… (Server status…), Version row › Mettre à jour… (Update…) or Rechercher (Check). The new version is then offered automatically to the members' PCs.
  • Seen from the website: Settings › Server shows the server's name and version followed by "up to date", or, for administrators, "Server update: version X available", with a reminder that it is installed from the server PC (click the icon next to the clock › Voir la mise à jour…).
  • Phones: nothing to do. The new version applies itself in the background, or a banner offers Refresh. The app never reloads while the recorder is open.
  • Uninstalling (Windows Settings › Apps) removes the program, the service, the automatic startup and the settings, but keeps your files in the 28JoursBox folder and all the server's data: reinstalling finds everything again. Note: the PC's hidden local trash (.sync) is deleted.

The synced folder

Work in the 28JoursBox folder like in any other folder: whatever you put in it reaches the other members, and vice versa. All the files really are on your drive, so they're available offline.

In Windows File Explorer

  • Status column with the usual Windows icons: green check mark = synced, blue arrows = in progress.
  • Verrou 28JoursBox (28JoursBox lock) column: "Verrouillé par X" (Locked by X) or "Erreur : …" (Error: …).
  • The working folders of music programs (see below) are marked "Exclu (non synchronisé)" (Excluded (not synced)).
  • The first time you open a folder, the view is set to a list showing the date created, newest at the top. The original creation date is kept from one PC to the next, so you can see when a take was really recorded.

What isn't synced

  • Technical files: Thumbs.db, desktop.ini, .DS_Store, ~$*, *.tmp, *.peak…
  • Music program caches: next to a Cubase project (.cpr): Images/, Auto Saves/, *.bak, *.csh; next to a Studio One project (.song): Cache/, History/, *.autosave, *.song.bak.
  • Your own exclusions: create a .syncignore file at the root of the 28JoursBox folder, one pattern per line (* and ?; a trailing / for a folder; # for a comment). It takes effect as soon as it changes.
  • Names Windows doesn't allow (: * ? " < > |, a trailing period or space, CON, NUL…) are refused.

Conflicted copies: nothing is ever overwritten

If two people change the same file at the same time, the server's version keeps the name and yours becomes nom (copie en conflit de NOM-DU-PC 2026-10-09).ext, which is sent to the band. Same thing if you change a file locked by another member. A change always wins over a deletion. You'll find them in the panel's Copies en double (Duplicate copies) row.

Trash, versions and mass deletions

  • A deleted file goes to the server trash for 30 days, and every file has a 30-day version history: see Trash and versions.
  • Anything the sync removes or replaces on your PC is also kept for 30 days in the hidden folder 28JoursBox\.sync\trash.
  • Safety pause: if more than 500 files, or more than 20% of the folder, are deleted within 10 minutes, the deletions are put on hold (orange icon, Suppression massive détectée (Mass deletion detected) banner in the panel). Choose Supprimer aussi sur le serveur (Also delete on the server) (recoverable for 30 days from the trash) or Restaurer les fichiers (Restore the files).
  • Transfers can resume: a dropout in the middle of uploading a session of several GB loses nothing. A file that's still being written is only sent once it's stable.

Cubase and Studio One projects: locks

When you open a .cpr (Cubase, Nuendo) or .song (Studio One) project from the 28JoursBox folder, the app recognizes it from the window title and puts a lock in your name on it. The other members see the file as read-only, "Verrouillé par …" (Locked by …) in File Explorer and the panel, and get a Projet verrouillé (Project locked) notification if they try to open it (their changes would become a conflicted copy).

  • The lock is renewed every 2 minutes and expires by itself after 10 minutes if your PC drops off. When you close the project, the final upload happens, then the lock is released.
  • Media (WAV) goes before the project file: when the others open it, nothing is missing.
  • Manual lock: panel › Projets › (Projects) › Prendre la main (Take over) / Libérer (Release), or the project's ⋯ menu in the web interface. A lock taken by hand isn't released automatically.
  • While a music program is open, syncing is throttled so it doesn't get in the way of recording (adjustable in Préférences (Preferences) › Vitesse (Speed)).

Moving the 28JoursBox folder

  1. Close your open projects and audio files.
  2. Préférences (Preferences) › Dossiers (Folders) › Déplacer… (Move…), choose the new location (empty, on an NTFS drive, with enough space), then confirm.
  3. On the same drive, it's instant; on another drive, everything is copied and checked before the old folder is deleted (progress bar, Annuler (Cancel) button). Nothing is sent back to the server.

Getting around

  • Bottom bar: Home (main folder), Search, Recent (the last 100 files changed by the band), Shared (public links), Trash, Settings. On PC, the left menu adds the Add button. With a mouse: one click selects, a double click opens (a song opens in the advanced player), Shift+click selects a range, Ctrl+click adds or removes a file.
  • Open a folder: tap it. Go back up: the ‹ arrow at the top, the phone's back button, or swipe right from the left edge of the screen: you go up to the parent folder, one level at a time, all the way to Home.
  • Tapping the folder name at the top opens Go to: all the folders above, to jump up in one go.
  • Refresh: the button at the top right, next to the sort button, or pull the list down. The list also updates by itself.
  • The app reopens the last folder you viewed, at the same spot.

Sorting

The sort button at the top right (e.g. Name ↑) opens Sort by: Name, Date, Type, Size; tapping the active choice again reverses the order. Folders stay on top. Each folder keeps its own sort order: the administrator's applies to the whole band, a member's applies only to them (on all their devices).

Gestures on a row

  • Tap a song: it loads in the mini player, paused. The other songs in the folder make up the play queue.
  • Tap any other file: full-screen viewer (photos, videos, PDF, Office, text).
  • Swipe the row to the left: quick buttons. For an audio file: Edit, Player, WAV, Rename, Delete (trash).
  • Long press: a short vibration. Let go without moving to start selecting several files (see below); drag to move the item by dropping it on a folder, on the ‹ arrow (parent folder) or on Home. The message offers Cancel.
  • Long press on an empty area of the list (right-click on PC): Paste text (details) and New folder.

Pasting text

Text copied somewhere else (lyrics, a chord chart, an email) becomes a .txt file in the folder you're viewing.

  1. Copy the text in another app.
  2. In 28JoursBox, long-press an empty area of the list (right-click on PC) › Paste text, or the + button › Paste text. On PC, Ctrl+V in the list does the same. The phone may ask you to allow "Paste".
  3. The Paste text window suggests a File name taken from the first words, which you can change. Tap Send.
ℹ️

Only text can be pasted: phones don't pass copied images, videos or documents on to web apps. For those, use + › Phone files.

Importing the sound from a YouTube video

  1. Copy the video's link (or, on Android, share the video from the YouTube app to 28JoursBox).
  2. + › Import from a YouTube link, then Paste. File name is optional (the video's title otherwise). Tap Import.
  3. Watch "Downloading N %" then "Converting to m4a…". You can close the window: the import keeps going. When it's done: "Imported: name.m4a". The song is then analyzed like the others.

On PC: copy the link, then the panel's ⚙ gear › Importer l'audio d'un lien… (Import the audio from a link…), choose the folder, Importer ici (Import here).

⚠️

Limits: one import at a time, videos of 2 hours at most, no playlists or live streams, public sites only. If YouTube refuses for a moment, two more tries are made automatically; a video that's too long is reported with its length and title. An imported song stays within the band: it can't be shared by public link. Respect the rights to the works and the sites' terms.

Listening: the mini player

  • At the top: the title (and its folder) with the cross to close it, then the position bar. Below, a well-spaced row: Loop on the left, previous / play / next in the middle, Advanced player on the right.
  • At the end of a song, the mini player stops (it doesn't move on to the next one). Loop (off at first) goes straight from the end back to the start, with no gap.
  • It keeps playing on the lock screen, on headphones and in CarPlay (play, previous/next track, ±10 s).
  • A song that's playing keeps its mini player while you scroll. A file that's just selected (paused) and scrolls off the screen is deselected, and the mini player closes. Swipe the mini player up to open the advanced player.
  • WAV and AIFF files play from a lightweight listening version (about 5 times smaller) prepared by the server: 1 to 2 seconds the first time, then instant. A rehearsal recorded in WAV plays over 4G with no waiting.
  • The last 10 songs opened in the advanced player are kept on the phone: reopening them is instant, with no new download (a song that changed is downloaded again). They are deleted when you sign out.

Viewing photos, videos, PDFs and documents

  • Photos and videos: full screen, landscape works too. Swipe or use the arrows to go to the other files in the folder.
  • PDF: zoom buttons and page counter. Tapping the document switches it to full screen, page by page; swipe to turn the pages.
  • Word, Excel, PowerPoint: shown like a PDF if LibreOffice is installed on the server PC. Numbered lists look the same as in Word.
  • Text (lyrics, ChordPro charts, .txt, .csv…): shown as plain text, black on white (Aptos font).
  • MKV, AVI or WMV movies: converted to MP4 overnight (5 per night) so they also play on iPhone. On iPhone, big downloads (a movie…) open in a built-in Safari window; Done takes you back to the app.
  • Other files (projects, archives): a card with Download.

Transcribing a meeting or a memo to text

To keep a written record of a band meeting, a voice memo or dictated ideas: the server turns speech into text, on your PC, with no online service (25 European languages, punctuation included).

  1. ⋯ menu of an audio or video file › Transcribe to text.
  2. Say how many people are speaking (or "I don't know"): it helps tell the speakers apart.
  3. The server works in the background (about 4 minutes per hour of recording, a bit more with speakers) and drops a .txt file with the same name in the same folder: just the text, in paragraphs, with "Speaker 1: …", "Speaker 2: …" when several people speak. In the app, text files are shown black on white, easy to read.
  4. Open the .txt, then Copy the text to paste it somewhere else, or Send (WhatsApp, Signal…).
ℹ️

Only one transcription at a time on the server, so it stays smooth. Transcription is meant for speech: it doesn't transcribe lyrics sung over music.

Split a gig or rehearsal into songs

Recorded a whole gig, a whole rehearsal or an album in one go? The server finds the pieces of music and saves each one in its own file.

  1. ⋯ menu of the audio file › Split into music pieces.
  2. Choose the minimum length of a song: 30 seconds, 1 minute, 1 min 30, 2 minutes or 3 minutes. Shorter passages (tries, bits of riffs) are left out, as are talk, applause, tuning and silence.
  3. The Put them in a subfolder "Name" checkbox: checked at first, and your choice is remembered on the device. Unchecked, the songs are saved next to the recording.
  4. Progress is shown, then the result, for example "8 music pieces saved in "Concert…"".
  5. The songs are numbered in order ("Name - 01", "Name - 02"…), in the same format and quality as the original (no re-encoding). The original isn't touched.

Music is told apart from talk and applause: softly played intros are kept, and the talking between songs is spotted. An album, a CD or a studio recording, with real silences between the songs, is cut exactly in the gaps, keeping the soft intro and the fade-out; for a gig, each cut is moved to the nearest gap. It's quick: a one-hour gig in high-resolution WAV is analyzed in a few seconds.

Merging audio files

To put several recordings end to end in a single m4a file, in the order you selected them.

  1. Select at least two audio files (long-press the first one, then tap the others in the order you want), then Merge in the bottom bar.
  2. The Merge N files window shows the list Dans l'ordre de sélection : (In selection order:) and each song's tempo.
  3. Different tempos? Check Aligner le tempo de tous les morceaux sur … BPM (Align the tempo of all the songs to … BPM): the average is suggested, and you can change it from 40 to 240 BPM. Each song is sped up or slowed down without changing the pitch. A song in half time (70 versus 140) counts as the same tempo.
  4. Check the Nom du nouveau fichier (Name of the new file), which suggests the first file's name followed by "(fusion)", then tap Merge. The new file is saved in the first file's folder.

The checkbox only becomes active once the tempo of every song is known: the analysis starts if needed, with a 40-second wait at most.

Photos → text

To get the text of printed or handwritten pages (lyrics, setlist, meeting notes):

  1. A folder's + button › Photos → text. The viewfinder opens in the app: tap the circle for each page, one after another. Phone photos adds photos you've already taken.
  2. Thumbnails are numbered in order. Tapping a thumbnail opens it large with a frame: drag an edge or a corner, then Crop; or Remove to take it out of the series.
  3. Done: the server reads the text in the photos (on the server PC, nothing to install), even on crooked, blurry or badly lit photos, and puts it back into paragraphs.
  4. A "Texte des photos date.txt" (Text of the photos) file is saved in the folder, and the text that was read is copied to the clipboard automatically (if the phone refuses, the message offers Copy the text). The photos aren't kept.

Photos → PDF

To gather photographed pages (sheet music, lyrics, a contract) in a single PDF, one page per photo, in order.

  1. A folder's + button › Photos → PDF. Same viewfinder as for Photos → text: shots one after another, Phone photos, Crop or Remove on each thumbnail.
  2. The Read the text (searchable PDF, text copied) checkbox: the text that was read is laid invisibly over the photos. The PDF becomes searchable, its text can be selected, and it is copied to the clipboard automatically.
  3. Done: the PDF is saved in the folder.

Photos are sent as JPEG, the right way up, 3,200 pixels at most; iPhone HEIC photos are accepted. The text is read on the server PC.

Searching

Search finds part of the name (not the content), ignoring accents and capital letters: "mix", ".cpr", "bass". Results show up as you type, each with its folder. On PC, the top bar offers suggestions.

Sharing and inviting

Public link (for someone outside the band)

  1. ⋯ menu of a file or folder › Share a link.
  2. Optional: a Password. The Expiry date is set to 3 months from now; clear the field for a link with no end date.
  3. Create the link, then Copy or share.

The person sees the file (audio player, photo, video, PDF) or browses the folder, read-only, and can download. Manage all the band's links in Shared: Copy the link, Revoke (the link stops working right away). A link can't be edited: create a new one and revoke the old one. Home and songs imported from YouTube can't be shared.

Sending by email

The email goes out from the server: no need for a mail app. ⋯ menu › Send by mail…, type the addresses (addresses you've already used are suggested), an optional message, then Send. The subject is written for you ("🎵 title — from nickname"). The song is attached as m4a; above 13 MB in total (or if the mail server refuses the size), the email still goes out, with a listening link valid for 30 days for each file. Limits: 10 recipients per send, 20 sends per hour per member. The administrator must have set up email sending.

Sending by WhatsApp (or another app)

⋯ menu › Send (WhatsApp, Signal…), for any file. For a song, the m4a file is prepared on the phone ("Ready: name (X MB)"), then Share opens the phone's share sheet: WhatsApp, Signal, Messages… The song goes out as m4a, not compressed like a voice note.

Inviting a member

Settings › Invite someone › Show the link and password: the link with Copy and Share the link, the band's password, and Email the PC app. The link uses the 4G address if it's set up. On a PC, the panel's Inviter (Invite) button also gives the link and a QR code. The group password is changed from the app on the server PC (details).

The family space

A second, separate file space for people close to you who aren't in the band (family, friends): photos, videos, documents. It has its own password and its own invitation link. Family members only see their own files; band members see nothing of the family space (not in the lists, search, recent files, trash or shared links, nor on their PC).

  1. Turning it on admin: Settings › Group › Family space card, check Family space turned on.
  2. The card shows the Family space password (Copy; Choose… a password of at least 8 characters, or Renew to draw a new one; changing the password signs the family members out), the Copy the invite link button and the Family members list (Disabled checkbox, deletion).
  3. Inviting someone: send them that link. They open it, just pick a nickname and they're in. The password lets them sign in with their nickname on another phone.
  4. Switching from one space to the other admin: with administration rights unlocked, Settings › Group › Space shown, Group and Family space buttons.

A simple mode: the top of the root shows "Family space" instead of the band's name, and a "family space" badge appears in Settings. It offers uploading and downloading files, Photos → text, Photos → PDF, Paste text, movies, the mini player, transcription, shared links and email. No music tools: no advanced player, no recorder or audio editor, no WAV conversion, To Studio One / Cubase, splitting, merging or YouTube import, and no music processing (analysis, chords, tracks) on its files.

The advanced player

Your pocket rehearsal studio: each song cut into color-coded sections, with its chords, its separated instruments, adjustable tempo and sample-accurate loops.

Opening and closing

  • Open: a song's ⋯ menu › Advanced player; swipe the row to the left › Player; or in the mini player, the Advanced player button, tap the title, or swipe the mini player up.
  • The player never starts on its own. Opened from the mini player, it picks up at the same position, paused.
  • Close: the ↓ chevron at the top left, swipe the header down, or the back button. Playback stops; the mini player keeps the position.
  • If the analysis isn't ready yet, "Analyse du morceau…" (Analyzing the song…) shows for a few seconds. If no analysis is possible, the player switches to simple playback (no blocks, ⏪ and ⏩ jump 10 s).

What you see

Fixed section colors, the same from one song to the next: Intro purple, Couplet (Verse) blue, Pré-refrain (Pre-chorus) cyan, Refrain (Chorus) pink, Pont (Bridge) yellow, Solo orange, Break gray, Outro green. A section is made of cycles lettered A, B, C…: two identical cycles get the same letter.

Behind the waveform, light lines mark the beats (light gray) and the bars (darker). The waveform stays sharp when zoomed right in, and zoom goes three times further once the song is in memory.

Tempo and key

  • BPM: tap to open the Tempo window (−1, slider, +1, shortcuts 75 %, 90 %, original). Or hold, then drag up or down: the value applies when you let go. From 50 % to 150 %, without changing the pitch. The server prepares the stretched version ("Tempo en service" (Tempo in progress)) while playback continues. Your tempo is remembered per song, on all your devices.
  • TON (key): hold, then drag to transpose from −6 to +6 semitones. Tap to open Gamme et accords (Scale and chords): the key, the notes of the scale, the suggested pentatonic for improvising, the song's chords, Transposer (Transpose), Tonalité originale (Original key; correcting it applies to the whole band) and Notation C D E or Do Ré Mi.
  • Heard right away: a change of tempo or key can be heard at once, worked out on the phone while the server prepares its version; if the device is too slow, the work goes back to the server automatically. It starts 0.3 s after you let go of the slider (2 s after the + and − buttons), and several changes in a row make a single request. When you go back to the original, the screen says "Retour au tempo d'origine…" (Going back to the original tempo…) then "Tempo d'origine en service" (Original tempo in use) (the same goes for the key and the mix).
  • The key is detected correctly 94% of the time on the band's recordings; a key corrected by hand by a member always comes first. On iPhone, the song is decoded by the phone's chip and kept on the device (1 GB at most): it's ready very quickly, going back to the original tempo is instant, and the song from the mini player is picked up with no new download.

Loop, metronome and trainer

  • Boucle (Loop): on when the player opens. With a selection, only the selection loops, sample-accurate; with no selection, the whole song. Even a drum loop a few seconds long restarts with no dead time at all.
  • Suivre (Follow): the view follows the playhead, page by page.
  • Outils (Tools):
    • Décompte d'une mesure (One-bar count-in) before each start;
    • Métronome (Metronome) locked to the detected beats;
    • Entraîneur de tempo (Tempo trainer): first select the passage, then set Départ (Start), Arrivée (Target), Palier (Step: +1, +2, +5) and Passages (Passes: ×1, ×2, ×4), then Démarrer (Start). The loop speeds up at each step until "Objectif atteint" (Goal reached). A badge at the top lets you stop;
    • Utiliser l'analyse fine (Use the fine analysis) or Revenir à l'analyse de base (Go back to the basic analysis);
    • Réinitialiser… (Reset…): Remettre dans l'ordre d'origine (Restore the original order), or Revenir à l'analyse (Go back to the analysis; also erases the band's shared correction).

Tracks: separating the instruments and mixing

Once the instruments are separated, the chords are recalculated and more reliable.

High-quality separation (5 tracks)

An optional, much cleaner separation into five tracks: Chant (Vocals), Guitares (Guitars), Basse (Bass), Batterie (Drums) and Autres (Other). "Autres" holds everything else in the song: the five tracks together give back the song exactly. They replace the four quick tracks, and the mixer settings are kept.

  1. Advanced player › Pistes (Tracks) › High-quality separation.
  2. While it works, the mixer shows the progress as a percentage, with the time left: allow 18 to 20 minutes for 4 min 30 of music. You can close the player. An interrupted separation starts again with Resume high-quality separation (N%); a separation planned for the night starts right away with Speed up.
  3. A badge shows which version is in place: "high quality" or "quick version (4)".

Installing the model admin: the separation model is never shipped with 28JoursBox. The administrator installs it from a file they own (about 700 MB, .onnx), either:

  • in the web interface: Settings › Advanced › High-quality stem separation › Install from a file…. The row changes from "model not installed" to "installed ✓", with the number of songs in high quality and the space used;
  • on the server PC: État du serveur… (Server status…), "Pistes haute qualité : non installées" (High-quality tracks: not installed) row › Installer… (Install…).

The file is checked: "file present, but not the expected model" is shown if it isn't the right one. Without the model, nothing changes: four tracks, and no extra button. Once the model is installed, songs are also separated in high quality overnight; a separation that isn't finished picks up again the next night.

Chords and guitar diagrams

In the Accords (Chords) window, the chord you hear is framed and follows playback. Chords are recognized with a large vocabulary (sevenths, maj7, m7, dim, sus), including in softly played intros. When they are recalculated in the background, the old ones stay on screen in the meantime.

Gamme (Scale) tab: the song's scale on an upright neck, to scale, up to the 15th fret (the 12th marked in red, "octave"), for guitar, 4- or 5-string bass, as the full Gamme (Scale) or the Penta (pentatonic); the root is in red. For bass, chords are given as arpeggios. If you correct the key, the chords are recalculated. You can also get there by tapping the key box (Gamme et accords (Scale and chords) window).

  • The bass being played: during playback, the bass note shows on the neck (circled orange dot). The basse jouée (bass played) button shows or hides it. On guitar, a note that's too low is moved up an octave.
  • Realistic fingering: the hand stays in a four-fret position, the low end of the neck is preferred, the root is played on the open low string when possible, and a phrase played high stays in its position. ▲ ▼ arrows for the position: "auto", or a fixed "case 3" (fret 3), "case 5", "case 7", "case 9", "case 12". − and + buttons for the octave ("octave", "octave +1"…, from −1 to +2), at the same place on the neck.
  • Notes outside the scale (a note from a borrowed chord, an approach note, a passing note, a blue note) are kept, circled in purple, with what they are written next to them; a doubtful note is gray, with "?". A summary ("hors gamme : …", outside the scale: …) shows under the neck.
  • The bass notes are prepared overnight, from the bass track (in high quality when it exists). Without separated tracks, the bass line is estimated from the whole song ("Basse : estimée sur le morceau entier", Bass: estimated from the whole song), which is less reliable.

At the top of the Accords and Gamme windows, − / + set the tempo in 5% steps, and origine (original) goes back to it; the display shows "N BPM · N %".

Recording a take on top

  1. Go back to the original tempo and key (required for a take).
  2. The first time on this phone, measure the mic delay: no headphones, volume up, somewhere quiet, tap Mesurer (Measure, 8 clicks). This setting is also in Pistes (Tracks) › Réglage de la latence micro (Mic latency setting).
  3. Plug in headphones (wired if possible): the mic must not hear the song.
  4. In Pistes, choose what you want to hear (for example everything except your instrument). Optional: select a passage with Boucle (Loop) to play it on a loop; as in a sequencer, only the last complete pass is kept.
  5. Tap ⏺: one bar of count-in, then playback and recording at the same time (red frame, duration, level meter). Tap ⏺ again or pause to stop.
  6. The take is lined up exactly with the song and becomes a file "Titre - Prise N.m4a" (Title - Take N) next to the song, shared with the whole band, and a track in the mixer.

Basic analysis and fine analysis

  • Basic analysis (red badge): a few seconds after the upload. Tempo, bars, cycles and sections named "Partie A", "Partie B" (Section A, Section B)…
  • Fine analysis (green badge): sections recognized and named (riffs, verses, solos…), more accurate. Done every night for m4a songs, or on request: tap the red badge › Utiliser l'analyse fine (Use the fine analysis; a few minutes, "Analyse fine N %" (Fine analysis N %); you can close the player), then Appliquer (Apply).
  • It automatically replaces the basic analysis. Revenir à l'analyse de base (Go back to the basic analysis) is a choice shared with the band, which the fine analysis will no longer replace.

Saving an edit, extracting a passage

  • After rearranging (moving, erasing, copying, repeating), tap Enregistrer (Save) at the top: Enregistrer le montage (Save the edit) creates "Titre (montage)" (Title (edit)) in the same folder, same format and same quality as the original, built by the server with no loss. Or Remplacer l'original (Replace the original): the original stays in the version history.
  • Extraire (Extract) saves only the selection (repeats included) to a new file. The Extraire la sélection (Extract the selection) window offers Morceau d'origine (Original song: same format, same quality) or Avec mon mélange (With my mix): exactly what you hear (muted or solo tracks, levels, takes, tempo, key), as m4a. Avec mon mélange stays grayed out until the mixer, the tempo or the key has been changed. The song itself isn't modified.

In the car and with the screen off

The player goes through the phone's built-in player: lock screen, control center and CarPlay all work, and "previous / next track" jumps from block to block. Loops and a changed tempo keep going with the screen off. After an interruption (GPS, call), playback resumes by itself. The count-in, metronome, takes and trainer are less reliable in CarPlay. The latest mixes and tempos can be replayed offline.

Recording and editing audio

Making a new recording

  1. In the destination folder: + › Record audio (or, with the app installed on Android, long-press the icon › Record audio).
  2. Allow the microphone if the phone asks. The sound is captured raw: no noise reduction, no automatic gain.
  3. Tap the big red button. The waveform draws itself live; "SAT" lights up if the signal clips (move the mic further away).
  4. Tap the red button again to stop. The app preselects the part you played (without the talking at the start and end) and normalizes the level: tap Garder (Keep) to keep only the music.
  5. Listen, touch it up if needed (tools below), then tap Sauver (Save), at the top right, away from the red button.
  6. The Sauver la prise (Save the take) window: enter a Titre (Title) (the file will be called "YYYYMMDD Title.m4a"), then:
    • Envoyer maintenant (Send now): sends it to the server and converts it to m4a;
    • Envoyer plus tard (Send later): perfect at a rehearsal with no network. The take stays on the phone, and a banner "N takes not sent (size) — kept on this phone" shows up in the file list; tap Send all later (details).
💡

No take is ever lost: while recording, the sound is written to the phone every 10 seconds. If the app is closed, the iPhone locked or the page reloaded, the take is pieced back together when you return (Take recovered). After a short interruption (a call), recording resumes by itself, and the app never updates while the recorder is open. There's no length limit. A take leaves the phone lossless (FLAC) and is only erased from it once it has been checked on the server.

⚠️

The red button asks for confirmation ("Nouvelle prise ?", New take?) if the previous take hasn't been saved. If you close without Sauver (Save), the Quitter sans sauver ? (Quit without saving?) window warns you: the take goes to the phone's trash (recoverable for 30 days; Annuler (Undo), in the message that follows, brings it back right away) and is no longer offered for sending. You need the https address (invitation link) and Safari (iPhone) or Chrome (Android). Microphone blocked on iPhone: "aA" in the address bar › Website Settings › Microphone › Allow.

Takes on this phone and recovered takes

  • Takes on this phone: from the file list's banner ("N takes not sent (size) — kept on this phone"), Send all, or the Takes on this phone list: every take kept on the phone, with Send, Listen, Share (or Save to Files), rename, change folder, delete.   • Checked uploads: takes upload by themselves, in pieces, and resume after a dropout. The phone's copy is only removed once the server has checked it. The lossless original (FLAC) is kept on the server and can be downloaded from the version history.

Recording to a click (metronome)

Recording over real drums

In the recorder's Métronome (Metronome) window, the Son (Sound) is a real drum kit recorded in a studio by default (the Clic (Click) is still an option): a kit suited to each style, several dynamics and alternating hits for a human feel. Each style offers ten patterns, so a hundred reference grooves (Motown, one drop, rockers and steppers, real bossa clave, jazz ride, Texas shuffle, train beat…), each at its usual tempo.

  1. Open the recorder (+ › Record audio), tap the metronome button and turn it on: drums are the suggested sound.
  2. Choose the style (Rock, Pop, Ballade, Funk, Disco, Hip-hop, Reggae, Bossa nova, Jazz with the Jazz aux balais (Jazz with brushes) option, Blues shuffle; Valse (Waltz) in 3/4, 6/8), then the pattern. Tapping a style or a pattern plays it right away, on a loop; changing the tempo or pattern while listening restarts it. Set the volume.
  3. Plug in headphones: the drums are then not recorded, only your instrument is.
  4. Tap the red button: a stick count-in, then the drums play while you record. Just like with the click, the take is aligned to the grid.

A style's kit downloads the first time (5 to 8 MB), then stays on the phone. Sound credits, shown in the app: DRSKit (DrumGizmo.org, CC BY 4.0), Virtuosity Drums (Versilian Studios), Big Rusty Drums (Karoryfer Samples).

The take split into cycles

After the take, the server finds the cycles, just like in the advanced player, and shows them as numbered blocks above the waveform ("Recherche des tournes…" (Finding cycles…) while it works; tap the message to try again if it fails).

  • Tapping a block plays it on a loop; tapping other blocks extends the selection.
  • Adjusting a boundary: the top handle snaps to bars (a little "click" at each bar, with a bubble "4 mes. │ 4 mes." (4 bars │ 4 bars)), or the round bottom handle for fine-tuning (the boundary moves half as much as your finger). When zoomed out, handles that are too close together are hidden: zoom in.
  • Boucler (Loop): loops the selection, or the whole take if nothing is selected, with no gap; after Garder (Keep), the loop keeps going over what you kept.

Perfect for a quick demo: find the good part, loop it, keep only what you need.

The editing tools

Select: press a little longer on the waveform, then drag (with a mouse: just drag); pull the handles to adjust. Zoom: pinch; double-tap to show everything.

Aligning to the grid

So that a recording dropped at the start of a music program, at the same tempo, lands right on the grid.

  1. After a take with the metronome, the Caler la prise sur les mesures ? (Align the take to the bars?) window opens by itself; otherwise, tap Caler (Align). It sums up in one sentence what will be done: tempo, time signature, number of bars.
  2. Tap Écouter le début (Listen to the start) to check the beginning.
  3. Oui, caler (Yes, align) trims the start and end on bar lines (the "1" is found from the kick and snare, and silence is added if needed); Non, garder telle quelle (No, keep it as is) leaves the take untouched.
  4. The fine settings are folded away: tempo (left empty, it is measured), time signature, shifting the start by one beat or one bar.

The ruler then switches to numbered bars, and the grid goes along with the file for its analysis. A take with no rhythm, one that's too short (less than 4 s of music) or one played without a click with a drifting tempo is refused, with an explanation.

Editing an existing file

  1. ⋯ menu of an audio file › Edit the audio (or swipe the row › Edit). Formats: wav, m4a, mp3, aif, aiff, flac.
  2. Trim, add your fades, normalize (same tools as above; plus Écouter la sélection (Play the selection) and Boucle sur la sélection (Loop the selection)).
  3. Save. For an m4a or a WAV, Sauver (Save) creates a new version of the same file (the old one stays in the history); Sauver comme nouveau fichier (Save as a new file) creates "Name (edited)". An mp3, aif or flac gives you a copy in .m4a.

Only the list of changes goes to the server, which rebuilds the file from the original, with no loss of quality. If someone changed or locked the file in the meantime, the app offers to save it as a new file.

Converting to WAV

⋯ menu › Convert to WAV…: Bit depth 16, 24 (default) or 32-bit float, Sample rate 44.1, 48 (default), 88.2 or 96 kHz, then Convert. A new .wav file is created in the same folder, from the original; the original does not change.

To Studio One and Cubase

Turns a song into a ready-to-open Studio One project, always multitrack in high quality, with a grid locked to the playing, even for a rehearsal played without a click.

  • One track per instrument, with fixed colors: Vocals (sky blue), Guitars (yellow), Bass (red), Drums (blue), Other (purple), then the Mix (brown, muted) and the recorded takes below. All in 24-bit / 48 kHz WAV.
  • Grid locked to the playing: the project is at the song's average tempo, rounded to a whole BPM, and the music program stretches the audio itself so that every drum beat lands on the grid. The audio files remain the original take, untouched.
  • If the separation is missing, it's done on the server without blocking the app: a badge follows the progress ("séparation haute qualité N % (≈ N min)", then "création du projet…", creating the project), and tracking picks up again after a page reload. Without the high-quality model, the quick separation is used (a message says so).

Result: a "Song" folder (never overwritten: "Song 2"… if the name already exists) containing Song.song and a Media folder. The project file only appears once all the audio files are ready. Studio One opens zoomed out on the whole song, with no tempo track showing.

On a band member's PC, the folder shows up in 28JoursBox: just open Song.song. The project then locks automatically for the other members. The working folders of Studio One and Cubase (Cache, Images, Auto Saves, .peak and .bak files…) aren't synced. The project is always in 4/4.

To Cubase

Same idea for Cubase: the song's ⋯ menu › To Cubase… creates a project ready to open in Cubase 14 or later: a "Song Cubase" folder with the .cpr file and an Audio folder, the same colored tracks, the grid locked to the playing and the sample rate (48 kHz) set. When opened in Cubase from the 28JoursBox folder, the project also locks automatically for the other members.

Step by step: everyday uses

From rehearsal to a rearranged song

The whole journey, with no computer in the rehearsal room.

  1. At rehearsal: + › Record audio, red button, play, red button. Tap Garder (Keep) to keep only the part you played, trim and add fades if needed (details). To play over a groove instead of a click: Clic (Click) › Son (Sound) › Batterie (Drums) (details). The take arrives already split into cycles: tap a block to loop it (details).
  2. No network? Save the take with Envoyer plus tard (Send later). Once you're back on the network, tap Send all in the banner of the file list. The take leaves lossless (FLAC) and picks up again by itself after a dropout; it arrives as m4a in the chosen folder.
  3. Let the server do the work: a few seconds after it arrives, the song has its tempo, bars, sections, A/B/C cycles and chords. Overnight, it is separated into vocals, guitars, bass and drums (plus "other" with the high-quality separation), then the fine analysis names the sections (details).
  4. Open it in the advanced player and rework the arrangement: long-press then drag to move a block or a section, Dupliquer (Duplicate), Effacer (Erase), Garder, Nommer (Name) (Intro, Verse, Chorus…), Répéter (Repeat) a loop ×N, Extraire (Extract) a selection. Annuler (Undo) takes back anything (details).
  5. Keep the result: Enregistrer (Save) at the top creates "Title (edit)" for the whole band (details).
  6. Add your part: headphones plugged in, the ⏺ button in the advanced player; the take is aligned with the music and shared with the band (details).
  7. Everyone's own version, then the music program: each member can suggest their own structure by saving their edit; the others listen to it in the band's folder. Once it's decided, ⋯ menu › To Studio One… (or To Cubase…) creates the project with the separated tracks, or take the WAV (Convert to WAV…) for any music program (details).
👥

Fixing the split (boundaries, names, letters) benefits the whole band; rearranging (moving, erasing, copying) stays personal until you save the edit.

Learning a song before rehearsal

  1. Open the song in the Advanced player.
  2. Find the structure on the sections strip and the chords on the row above it.
  3. Tap TON (Key) for the scale and the pentatonic, Accords (Chords) for the chord diagrams.
  4. Double-tap a block to select its section, then ▶: it plays on a loop.

Working on a hard passage, slowly

  1. Select the passage (tap a block, pull the handles).
  2. Hold BPM and slide down, or tap BPM › 75% › OK.
  3. Optional: Outils (Tools) › Décompte d'une mesure (One-bar count-in) and Métronome (Metronome).
  4. Once you've got it: Outils › Entraîneur de tempo (Tempo trainer), from 80% up to the original tempo, in steps of +2.

Muting your instrument and playing along

  1. Pistes (Tracks); if needed, Séparer (Separate) and wait.
  2. M on your instrument (for example Basse, the bass), or lower its slider.
  3. OK, wait for "Mélange en service" (Mix in use), and play along with the band.

Recording your part over the song

  1. Original tempo and key, mic delay measured once, headphones plugged in.
  2. Optional: select a passage with Boucle (Loop); only the last complete pass is kept.
  3. ⏺, play, ⏺ to stop. The take is in Pistes (Tracks) and in the song's folder, for the whole band.

The drummer records to a click, then into the music program

  1. + › Record audio › Clic (Click): Activé (On), tempo, time signature, 1-bar count-in. With your own click in your headphones: Clic silencieux (Silent click). OK.
  2. Red button: count-in 1, 2, 3, 4, then the take starts on the 1. Red button to stop.
  3. Caler la prise sur les mesures ? (Align the take to the bars?): Écouter le début (Listen to the start), then Oui, caler (Yes, align).
  4. Save and send. On the PC, drag the file to the very start of a project at the same tempo: the hits land on the grid. Or use To Studio One….

Cleaning up a rehearsal recording

  1. ⋯ menu › Edit the audio.
  2. Select the chatter and Effacer (Erase), or select the song you played and Garder (Keep).
  3. A short Fondu entrée (Fade in) and Fondu sortie (Fade out) at the ends, then Normaliser (Normalize) with nothing selected.
  4. Save: a new version, and the original stays in the history.

Trying a new arrangement

  1. In the advanced player: long-press a block and drag to move it, drag up to erase it, Copier (Copy) / Coller (Paste), Dupliquer (Duplicate), Répéter (Repeat) ×2.
  2. Listen on a loop, Annuler (Undo) if needed.
  3. Enregistrer (Save) at the top: a new file "Title (edit)" for the band.

Fixing the split for the whole band

  1. If the badge is red: badge › Utiliser l'analyse fine (Use the fine analysis) › Appliquer (Apply).
  2. Adjust the boundaries (top handle snaps to bars, round bottom handle for fine-tuning), Découper (Split) / Fusionner (Merge), Nommer (Name) the sections, long-press the sections strip for the letters. If the rehearsal starts with a count-in, drag the purple "1" handle to the first real beat.
  3. Fix the key if needed: TON (Key) › Tonalité originale (Original key).
  4. Don't rearrange at the same time (moving, copying, erasing): the split would become personal. To undo everything: Outils (Tools) › Réinitialiser… (Reset…) › Revenir à l'analyse (Back to the analysis).

Going from a rehearsal to the studio

  1. The song's ⋯ menu › To Studio One… (or To Cubase…).
  2. Keep Next to the song as the Project folder, then Create. Even a rehearsal played without a click lands on the grid.
  3. Once the progress badge is done, open Song.song (or the .cpr file) in the PC's 28JoursBox folder.

Sharing photos and videos from a gig

  1. In the band's folder, + › New folder, for example "Gig 2026-10-12".
  2. Open it, then + › Upload new photos and choose photos and videos from the gallery (the app reminds you of the date of your last upload). During the gig, Take a photo or a video sends what you shoot straight away.
  3. The upload picks up again by itself after a network dropout. The other members see the thumbnails right away and open photos and videos full screen; they also arrive in the 28JoursBox folder on their PC.
  4. For the venue or the fans: the folder's ⋯ menu › Share a link (password and end date optional). To grab everything at once: Download (zip), up to 500 MB.

Managing the server

🛠️

This chapter is for the person who looks after the server PC.

Managing from a phone or another PC

The group password (the one in the invitation link) does not give administration rights, except on the server PC. To manage things from anywhere else (trash, members, family space, group name and logo, fast access, sending mail…), you need an administrator password. It's also needed to sign in with an administrator nickname: for that nickname, the group password isn't enough.

  1. Once, on the server PC: Settings › Advanced › Administration rights › Set the password (at least 8 characters, asked twice; Show password to see what you're typing).

Security

  • Administrator nickname: signing in with that nickname asks for the administrator password (details).
  • Devices: Settings › My devices lists the PCs, browsers and phones signed in to your account; Disconnect closes the session of a lost or unknown device.
  • Progressive blocking: after several wrong passwords (signing in, invitation link, public links, administrator password), attempts are blocked for longer and longer.
  • Public links: an Expiry of 3 months is suggested when you create one (details).
  • The group password never travels in plain text over the local network; updates are signed, with no way back to an older version; the server's data is protected by the installer.

What the server does on its own

  • All the time: heavy processing is capped so the server stays reachable (analysis, chords and alignment on 3 cores max, instrument separation on 6, only one song or one transcription at a time).
  • At night (1 a.m. – 7 a.m.): for each m4a song, newest to oldest, one at a time: analysis, chords, instrument separation, detailed analysis. A high-quality separation that isn't finished picks up again the next night. Then the previews of Office documents (if LibreOffice is installed) and the conversion to MP4 of MKV, AVI or WMV movies (5 per night). WAV and MP3 files are analyzed on demand. Track progress in Settings › Server status.
  • Every hour: clears out the trash and versions older than 30 days.
  • Every day: backup copy of the database (7 kept), update of the YouTube import tool, cleanup of mixes nobody has played in 30 days, check for a new server version (details).
  • Every week (between 7 and 10 a.m.): full check of file integrity.

In a Command Prompt run as administrator, in C:\Program Files\28JoursBox:

  • 28JoursBox.exe move-server-data --to E:\28JoursBox-Serveur: move the data to a bigger drive. The service is stopped, everything is copied and checked, then it restarts. The old folder is only renamed (".ancien"): delete it once you've checked the server.
  • 28JoursBox.exe import-folder --from D:\AncienDossier: bring a folder from the server's drive into the group (to switch from another sync software without re-uploading everything from a PC). Folder structure and dates are kept; --move avoids copying when it's on the same drive. If it's interrupted, run it again and it picks up where it left off.
  • 28JoursBox.exe fsck: check the integrity of the storage ("Intégrité OK.").

Troubleshooting

SituationWhat to do
"The server is not responding" / "Offline" icon / "Server unreachable"Check that the server PC is on, not asleep, and that its network is set to the Private profile. On 4G, check outside access (server PC: État du serveur… (Server status…), Accès extérieur (Outside access) row). PCs keep retrying on their own.
"The group password has changed"Ask for the new link. PC: panel › Entrer le nouveau mot de passe (Enter the new password). Phone: open the new link.
"Too many attempts"Wait before trying again: after several wrong passwords, the wait gets longer each time.
A PC was reinstalledRun the setup wizard again with the link and choose the same folder: identical files aren't sent again, nothing is deleted. Then revoke the old PC in Settings › My devices.
Folders are missing on a PCPréférences (Preferences) › Dossiers (Folders) › Dossiers à garder sur ce PC (Folders to keep on this PC): check them, then Appliquer (Apply).
The File Explorer check marks are wrongPréférences (Preferences) › Général (General) › Dépannage (Troubleshooting) › Réparer les coches de l'Explorateur (Repair the File Explorer check marks).
Sync is slow when the music software is openThat's on purpose (sync is slowed down). You can adjust it in Préférences › Vitesse (Speed).
A "(copie en conflit de …)" (conflicted copy of …) file showed upTwo people edited the same file. Compare them, keep the right version, delete the other one (panel › Copies en double (Duplicate copies)).
"Preview unavailable: LibreOffice is not installed on the server."Install LibreOffice on the server PC.
"… FFmpeg is not installed on the server"The server was installed with the client installer: install 28JoursBox-Serveur-Setup.msi on the server PC.
The mic is blockediPhone: "aA" › Website Settings › Microphone › Allow. Android: padlock › Permissions › Microphone. The app added to the home screen remembers it.
"The sound could not start"Tap Play again (the phone requires a tap).
Takes are stuck "to send"Tap Send all in the banner of the file list, once the network is back, or open the Takes on this phone list.
The app closed during a takeReopen it: the take is pieced back together ("Take recovered"). Choose Send or Keep without sending.
"Server storage quota reached"The administrator raises QuotaBytes or frees up space (trash).
You need to report a problemAdministrator: Settings › Log › Copy, then ask your question on the forum. PC logs: Préférences › Général (General) › Dépannage (Troubleshooting) › Ouvrir les journaux (Open the logs).
Direct access won't turn onCheck the port forwarding on your internet router (to the server PC's fixed address, port 8443), the DuckDNS name and token, and turn off any VPN on the server PC; then Check now. In the meantime, everything goes through Tailscale.
