28JoursBox in 2 minutes

28JoursBox connects three kinds of devices around one shared band folder:

  • The server PC: a Windows PC belonging to the band that keeps all the files, runs the music analyses (at night) and stays on. Only one person installs it, and that person becomes the administrator.
  • The members' PCs: everyone gets a 28JoursBox folder on their Desktop that syncs with the server all by itself.
  • Phones (and any browser): nothing to install. Open the invitation link and you'll find all the files, the advanced player, the recorder…
🏠

Everything stays at home. Files, versions, takes, analyses and separated tracks are stored on the server PC's drive, not in a data center; the AI processing runs on that PC, at night. The flip side: backups are the band's job (see Back up). Why this choice?

Nickname and group password

There are no personal accounts with passwords. Each member picks a nickname, and a single password covers the whole band. It's already built into the invitation link, so in practice you never have to type it.

⚠️

Always use the same nickname on all your devices, and never use another member's: a nickname that already exists opens that member's session (capitals don't matter, "Marc" = "marc"). A new nickname creates a new member.

How to read this guide

  • Button and menu names are written as they appear in the app: Advanced player.
  • admin marks what only the band's administrator can do. On any device other than the server PC, you first need to unlock administration with the administrator password.
  • "Tap" is for the phone; on a PC, it's a click. "Long press": keep your finger down for about half a second.
  • A file's ⋯ menu opens with the ⋯ button on its row, with a long press on the row, or with a right-click on a PC.

Installing

The server PC (just once)

This is for the person who manages the band, on the PC that will keep the files. First check the system requirements.

  1. Download and run 28JoursBox-Serveur-Setup.msi (Download page) and accept the Windows administrator prompt. The MSI installs the "28JoursBox Server" Windows service, which starts with the PC, even when nobody is signed in.
  2. When the installation finishes, the Serveur 28JoursBox installé (28JoursBox server installed) notification appears and the 28JoursBox icon shows up next to the clock. Click the notification or the icon (or, in its menu, Ouvrir l'interface web (Open the web interface)).
  3. The Setup page (First setup) asks for the Group name and Your nickname: you become the band's administrator. Click Create the group.
  4. The The group is ready page shows the group password and the invitation link: send the link to the members, then click Continue to the files. You can find the link anytime in Invite someone.

The server PC's icon (next to the clock) offers: Ouvrir l'interface web, Accès depuis l'extérieur (4G)… (Access from outside (4G)…), Synchroniser aussi des fichiers sur ce PC… (Also sync files on this PC…) and Quitter (le serveur continue de tourner) (Quit (the server keeps running)). By default, the server PC has no synced 28JoursBox folder: choose Synchroniser aussi des fichiers sur ce PC… if you also want to work on this PC (the members' setup wizard opens, and the full PC app with its Préférences (Preferences) becomes available).

What gets set up: the Windows service, a firewall rule (Private network only), and the data in C:\ProgramData\28JoursBox.

💡

To keep the server reachable: turn off sleep when plugged in (Windows Settings › System › Power), use a network cable, and make sure the Windows network is set to the Private profile.

Access from outside (4G): Tailscale

Out of the box, the server can only be reached from the home Wi-Fi. There are two solutions, which you can combine: Tailscale, the simplest (nothing to set up on the router), and direct access, which is faster. Members' PCs automatically pick the fastest route that responds: local network, direct access, then Tailscale. With Tailscale, only the server PC installs anything; phones and other PCs install nothing. The diagram of how it works and the detailed step-by-step (including router by router) are on the Access from outside page.

  1. On the server PC, icon menu next to the clock › Accès depuis l'extérieur (4G)… (Access from outside (4G)…) (on a server PC that also syncs files: Préférences (Preferences) › Serveur (Server), Accès depuis l'extérieur (4G) card). Click Installer Tailscale (Install Tailscale): the Tailscale download page opens; install it and sign in to Tailscale.
  2. Come back and click J'ai installé Tailscale, vérifier (I installed Tailscale, check) (or Vérifier à nouveau (Check again) if Tailscale wasn't connected yet).
  3. Click Activer l'accès extérieur (Turn on outside access). The first time, a Tailscale page opens: allow Funnel, then come back. Accept the administrator prompt.
  4. Result: "Accès extérieur activé : https://<pc>.<nom>.ts.net" (Outside access turned on). The invitation link now uses this address. At home, PCs keep going through the local network (faster for big WAV files).

The server PC checks the publication every 5 minutes and restores it if needed. If you rename the machine in Tailscale, a Nouvelle adresse du serveur (New server address) notification appears: click it to apply it. Alternatives for advanced users: Cloudflare Tunnel, or port forwarding on the router with a proxy (Caddy), by setting PublicUrl in server.json.

Direct access (faster, without Tailscale) admin

Tailscale's relays are often limited to a few MB/s. With direct access, members connect straight to the server PC's router: much faster for big syncs and for playing a WAV on your phone. Tailscale stays as a backup, and direct access can be turned on or off at any time.

🧭

Detailed step-by-step, with the exact menus of the Orange, SFR, Bouygues and Free routers, how to give the server PC a fixed address and what to do if it doesn't work: Direct access step by step and Router by router.

  1. On duckdns.org (free): sign in (with a Google account, for example), reserve a name (e.g. "myband") and copy the token shown at the top of the page.
  2. On the router (Livebox: http://192.168.1.1, Network menu): under Baux DHCP statiques (static DHCP leases), always give the server PC the same address.
  3. Still on the router, NAT/PAT: forward port 8443 (TCP) to the server PC's address, port 8443. (Use 443 only if the router allows it: the address then shows no port.)
  4. In 28JoursBox: Settings › Accès direct (sans Tailscale) (Direct access (without Tailscale)), fill in Nom DuckDNS (DuckDNS name), Jeton DuckDNS (token) (DuckDNS token) and Port ouvert sur la box (Port open on the router), check Activer l'accès direct (Turn on direct access), then Enregistrer (Save). The HTTPS certificate (Let's Encrypt, free) is obtained in one to two minutes, then renews itself.
  5. Test it on a phone on 4G (Wi-Fi off) by opening the fast address shown, or tap Vérifier maintenant (Check now).

The card shows the status ("Active: members' PCs go through direct access"), the router address that was checked and the certificate's expiry date. Members' PCs follow along by themselves, with nothing to do. Phones keep the address of the installed app; listening and downloads go through direct access when it responds, falling back to Tailscale automatically.

⚠️

A VPN running on the server PC can block direct access. Opening a port on the router exposes the server to the Internet: it's protected by HTTPS and by the group password; keep Windows up to date. By turning it on, you accept the Let's Encrypt terms of use.

Members' PCs

  1. The easiest way: open the invitation link in the PC's browser and click Install 28JoursBox on this PC. The link is copied to the clipboard automatically. Otherwise, download 28JoursBox-Client-Setup.msi.
  2. Run the downloaded file. The wizard opens and finds the band by itself thanks to the copied link ("✓ Groupe …" box). Otherwise, paste the link into Lien d'invitation (Invitation link). No link? Pas de lien ? Saisir l'adresse et le mot de passe (No link? Enter the address and password).
  3. Choose Votre pseudo (Your nickname), then C'est parti (Let's go).
  4. A single page then brings together the folder location, the space gauge (at the very top, as soon as the space needed is known) and the choice of folders to keep on this PC. The gauge compares your selection with the disk space (keeping 10% free): green, orange, or red if it doesn't fit; another drive is suggested if the one you picked doesn't have room. The ‹ Retour (‹ Back) button goes back to the link and nickname page. Confirm with Synchroniser ces dossiers (Sync these folders).
  5. C'est prêt ! (All set!): the 28JoursBox folder is on the Desktop, with a 28JoursBox (web) shortcut to the web interface, and the app starts with Windows. This shortcut (like Ouvrir l'interface web (Open the web interface) in the app) opens the interface already signed in, through direct access when it responds, otherwise through Tailscale.

Locations not allowed for the folder: a network folder, the root of a drive, a drive that isn't NTFS, a OneDrive folder or a folder already synced by another program. If your Desktop is in OneDrive, the folder goes into your personal folder with a shortcut on the Desktop.

ℹ️

Messages you might see: "Ce lien n'est plus valable : le mot de passe du groupe a changé. Demandez le nouveau lien." (This link is no longer valid: the group password has changed. Ask for the new link.), "Ce pseudo a été désactivé par l'administrateur du groupe." (This nickname has been disabled by the group administrator.), "Trop de tentatives : patientez une minute avant de réessayer." (Too many attempts: wait a minute before trying again.). With a self-signed HTTPS certificate, check Faire confiance à ce serveur (Trust this server).

Phones

  1. Open the invitation link (received by message, or by pointing the camera at the QR code shown by the PC: icon menu › Ouvrir sur le téléphone (QR code)… (Open on the phone (QR code)…)).
  2. Welcome! screen: type Your nickname, then Join.
  3. Add the app to your home screen to get it full screen and keep the microphone permission:
    • iPhone (Safari): Share button (square with an arrow) › Add to Home Screen › Add.
    • Android (Chrome): ⋮ menu › Add to Home screen or Install app. A tip card also suggests it at the top of the file list, and so does Settings › Install the app.

Another way: the Sign in screen with Pseudo (Nickname) and Group password (capitals, spaces and hyphens are ignored). The session lasts 30 days and is extended every time you use it. The app is used in portrait mode (except for photos and videos).

💡

On Android, the installed app offers shortcuts when you long-press its icon: Record audio, Téléverser des fichiers (Upload files), Recent. It also shows up in the Share menu of other apps (photos, audio, PDFs, YouTube links).

LibreOffice (previewing Office documents)

To view Word, Excel and PowerPoint files (and OpenDocument) on phones and in the browser, install LibreOffice (free) on the server PC only, in the default folder it suggests (C:\Program Files\LibreOffice). It's detected automatically, with no restart. Members' PCs and phones don't need it.

  • The first time a document is opened, the server converts it to PDF ("Preparing the preview…", 3 minutes at most), then keeps it: later openings are instant. New documents are also prepared at night.
  • Without LibreOffice, the app shows "Preview unavailable: LibreOffice is not installed on the server." with a Download button. Everything else works.
  • Installed somewhere else? Enter the path to soffice.exe in LibreOfficePath (server.json).
  • To check that it's detected: Settings › Server status › Tools, Document preview (LibreOffice) row (administrator).

Updates and uninstalling

  • Members' PCs: the app checks with the server 1 minute after startup, then every 6 hours. A Mise à jour disponible (Update available) notification appears; install it from the icon menu (Mettre à jour vers la version X… (Update to version X…)), the panel, or Préférences (Preferences) › Général (General). Syncing stops during the installation, then 28JoursBox restarts by itself. Updates are signed: a PC refuses any update that doesn't come from 28JoursBox.
  • Server PC: install the new server MSI over the old one, by hand. The service is replaced and restarted; the new version is then offered automatically to the members' PCs.
  • Phones: nothing to do. The new version applies itself when you open the app, or a banner offers Refresh.
  • Uninstalling (Windows Settings › Apps) removes the program, the service, the automatic startup and the settings, but keeps your files in the 28JoursBox folder and all the server's data: reinstalling finds everything again. Note: the PC's hidden local trash (.sync) is deleted.

The app on the PC

It lives in the notification area, next to the clock. If you quit it, start it again from the Start menu ("28JoursBox").

The synced folder

Work in the 28JoursBox folder like in any other folder: whatever you put in it reaches the other members, and vice versa. All the files really are on your drive, so they're available offline.

In Windows File Explorer

  • Status column with the usual Windows icons: green check mark = synced, blue arrows = in progress.
  • Verrou 28JoursBox (28JoursBox lock) column: "Verrouillé par X" (Locked by X) or "Erreur : …" (Error: …).
  • The first time you open a folder, the view is set to a list showing the date created, newest at the top. The original creation date is kept from one PC to the next, so you can see when a take was really recorded.

What isn't synced

  • Technical files: Thumbs.db, desktop.ini, .DS_Store, ~$*, *.tmp, *.peak…
  • Music program caches: next to a Cubase project (.cpr): Images/, Auto Saves/, *.bak, *.csh; next to a Studio One project (.song): Cache/, History/, *.autosave, *.song.bak.
  • Your own exclusions: create a .syncignore file at the root of the 28JoursBox folder, one pattern per line (* and ?; a trailing / for a folder; # for a comment). It takes effect as soon as it changes.
  • Names Windows doesn't allow (: * ? " < > |, a trailing period or space, CON, NUL…) are refused.

Conflicted copies: nothing is ever overwritten

If two people change the same file at the same time, the server's version keeps the name and yours becomes nom (copie en conflit de NOM-DU-PC 2026-10-09).ext, which is sent to the band. Same thing if you change a file locked by another member. A change always wins over a deletion. You'll find conflicts in the panel's Conflits (Conflicts) tab.

Trash, versions and mass deletions

  • A deleted file goes to the server trash for 30 days, and every file has a 30-day version history: see Trash and versions.
  • Anything the sync removes or replaces on your PC is also kept for 30 days in the hidden folder 28JoursBox\.sync\trash.
  • Safety pause: if more than 500 files, or more than 20% of the folder, are deleted within 10 minutes, the deletions are put on hold (orange icon, Suppression massive (Mass deletion) notification). In the panel, choose Supprimer aussi sur le serveur (Also delete on the server) (recoverable for 30 days from the trash) or Restaurer les fichiers (Restore the files).
  • Transfers can resume: a dropout in the middle of uploading a session of several GB loses nothing. A file that's still being written is only sent once it's stable.

Cubase and Studio One projects: locks

When you open a .cpr (Cubase, Nuendo) or .song (Studio One) project from the 28JoursBox folder, the app recognizes it from the window title and puts a lock in your name on it. The other members see the file as read-only, "Verrouillé par …" (Locked by …) in File Explorer and the panel, and get a Projet verrouillé (Project locked) notification if they try to open it (their changes would become a conflicted copy).

  • The lock is renewed every 2 minutes and expires by itself after 10 minutes if your PC drops off. When you close the project, the final upload happens, then the lock is released.
  • Media (WAV) goes before the project file: when the others open it, nothing is missing.
  • Manual lock: panel › Projets (Projects) › Prendre la main (Take over) / Libérer (Release), or the project's ⋯ menu in the web interface. A lock taken by hand isn't released automatically.
  • While a music program is open, syncing is throttled so it doesn't get in the way of recording (adjustable in Préférences (Preferences) › Bande passante (Bandwidth)).

Moving the 28JoursBox folder

  1. Close your open projects and audio files.
  2. Préférences › Dossier (Folder) › Déplacer… (Move…), choose the new location (empty, on an NTFS drive, with enough space), then confirm.
  3. On the same drive, it's instant; on another drive, everything is copied and checked before the old folder is deleted (progress bar, Annuler (Cancel) button). Nothing is sent back to the server.

On the phone: files

Getting around

  • Bottom bar: Home (main folder), Search, Recent (the last 100 files changed by the band), Shared (public links), Invite, Settings. On PC, the left menu adds Trash and the Add button.
  • Open a folder: tap it. Go back up: the ‹ arrow at the top, the phone's back button, or swipe right from the left edge of the screen: you go up to the parent folder, one level at a time, all the way to Home.
  • Tapping the folder name at the top opens Go to: all the folders above, to jump up in one go.
  • Refresh: the button at the top right, or pull the list down. The list also updates by itself.
  • The app reopens the last folder you viewed, at the same spot.

Sorting

The sort button (e.g. Name ↑) opens Sort by: Name, Date, Type, Size; tapping the active choice again reverses the order. Folders stay on top. Each folder keeps its own sort order: the administrator's applies to the whole band, a member's applies only to them (on all their devices).

Gestures on a row

  • Tap a song: it loads in the mini player, paused. The other songs in the folder make up the play queue.
  • Tap any other file: full-screen viewer (photos, videos, PDF, Office, text).
  • Swipe the row to the left: quick buttons. For an audio file: Edit, Player, WAV, Rename, Delete (trash).
  • Long press: a short vibration. Let go without moving to open the ⋯ menu; drag to move the item by dropping it on a folder, on the ‹ arrow (parent folder) or on Home. The message offers Cancel.

Importing the sound from a YouTube video

  1. Copy the video's link (or, on Android, share the video from the YouTube app to 28JoursBox).
  2. + › Import from a YouTube link, then Paste. File name is optional (the video's title otherwise). Tap Import.
  3. Watch "Downloading N %" then "Converting to m4a…". You can close the window: the import keeps going. When it's done: "Imported: name.m4a". The song is then analyzed like the others.

On PC: copy the link, then the icon menu › Importer l'audio d'un lien du presse-papiers… (Import audio from a link on the clipboard…), choose the folder, Importer ici (Import here).

⚠️

Transcribing a meeting or a memo to text

To keep a written record of a band meeting, a voice memo or dictated ideas: the server turns speech into text, on your PC, with no online service (25 European languages, punctuation included).

  1. ⋯ menu of an audio or video file › Transcribe to text.
  2. Say how many people are speaking (or "I don't know"): it helps tell the speakers apart.
  3. The server works in the background (about 4 minutes per hour of recording, a bit more with speakers) and drops a .txt file with the same name in the same folder: time-stamped paragraphs, "Speaker 1: …", "Speaker 2: …", a new paragraph each time the voice changes.
  4. Open the .txt, then Copy the text to paste it somewhere else, or Send (WhatsApp, Signal…).
ℹ️

Only one transcription at a time on the server, so it stays smooth. Transcription is meant for speech: it doesn't transcribe lyrics sung over music.

The advanced player

Your pocket rehearsal studio: each song cut into color-coded sections, with its chords, its separated instruments, adjustable tempo and sample-accurate loops.

Opening and closing

  • Open: a song's ⋯ menu › Advanced player; swipe the row to the left › Player; or in the mini player, the Advanced player button, tap the title, or swipe the mini player up.
  • The player never starts on its own. Opened from the mini player, it picks up at the same position, paused.
  • Close: the ↓ chevron at the top left, swipe the header down, or the back button. Playback stops; the mini player keeps the position.
  • If the analysis isn't ready yet, "Analyse du morceau…" (Analyzing the song…) shows for a few seconds. If no analysis is possible, the player switches to simple playback (no blocks, ⏪ and ⏩ jump 10 s).

What you see

Fixed section colors, the same from one song to the next: Intro purple, Couplet (Verse) blue, Pré-refrain (Pre-chorus) cyan, Refrain (Chorus) pink, Pont (Bridge) yellow, Solo orange, Break gray, Outro green. A section is made of cycles lettered A, B, C…: two identical cycles get the same letter.

Tempo and key

  • BPM: tap to open the Tempo window (−1, slider, +1, shortcuts 75 %, 90 %, original). Or hold, then drag up or down: the value applies when you let go. From 50 % to 150 %, without changing the pitch. The server prepares the stretched version ("Tempo en service" (Tempo in progress)) while playback continues. Your tempo is remembered per song, on all your devices.
  • TON (key): hold, then drag to transpose from −6 to +6 semitones. Tap to open Gamme et accords (Scale and chords): the key, the notes of the scale, the suggested pentatonic for improvising, the song's chords, Transposer (Transpose), Tonalité originale (Original key; correcting it applies to the whole band) and Notation C D E or Do Ré Mi.

Loop, metronome and trainer

  • Boucle (Loop): on when the player opens. With a selection, only the selection loops, sample-accurate; with no selection, the whole song. Even a drum loop a few seconds long restarts with no dead time at all.
  • Suivre (Follow): the view follows the playhead, page by page.
  • Outils (Tools):
    • Décompte d'une mesure (One-bar count-in) before each start;
    • Métronome (Metronome) locked to the detected beats;
    • Entraîneur de tempo (Tempo trainer): first select the passage, then set Départ (Start), Arrivée (Target), Palier (Step: +1, +2, +5) and Passages (Passes: ×1, ×2, ×4), then Démarrer (Start). The loop speeds up at each step until "Objectif atteint" (Goal reached). A badge at the top lets you stop;
    • Utiliser l'analyse fine (Use the fine analysis) or Revenir à l'analyse de base (Go back to the basic analysis);
    • Réinitialiser… (Reset…): Remettre dans l'ordre d'origine (Restore the original order), or Revenir à l'analyse (Go back to the analysis; also erases the band's shared correction).

Tracks: separating the instruments and mixing

Once the instruments are separated, the chords are recalculated and more reliable.

Chords and guitar diagrams

Recording a take on top

  1. Go back to the original tempo and key (required for a take).
  2. The first time on this phone, measure the mic delay: no headphones, volume up, somewhere quiet, tap Mesurer (Measure, 8 clicks). This setting is also in Pistes (Tracks) › Réglage de la latence micro (Mic latency setting).
  3. Plug in headphones (wired if possible): the mic must not hear the song.
  4. In Pistes, choose what you want to hear (for example everything except your instrument). Optional: select a passage with Boucle (Loop) to do one take per pass.
  5. Tap ⏺: one bar of count-in, then playback and recording at the same time (red frame, duration, level meter). Tap ⏺ again or pause to stop.
  6. The take is lined up exactly with the song and becomes a file "Titre - Prise N.m4a" (Title - Take N) next to the song, shared with the whole band, and a track in the mixer.

Basic analysis and fine analysis

  • Basic analysis (red badge): a few seconds after the upload. Tempo, bars, cycles and sections named "Partie A", "Partie B" (Section A, Section B)…
  • Fine analysis (green badge): sections recognized and named (riffs, verses, solos…), more accurate. Done every night for m4a songs, or on request: tap the red badge › Utiliser l'analyse fine (Use the fine analysis; a few minutes, "Analyse fine N %" (Fine analysis N %); you can close the player), then Appliquer (Apply).
  • It automatically replaces the basic analysis. Revenir à l'analyse de base (Go back to the basic analysis) is a choice shared with the band, which the fine analysis will no longer replace.

Saving an edit, extracting a passage

  • After rearranging (moving, erasing, copying, repeating), tap Enregistrer (Save) at the top: Enregistrer le montage (Save the edit) creates "Titre (montage)" (Title (edit)) in the same folder, same format and same quality as the original, built by the server with no loss. Or Remplacer l'original (Replace the original): the original stays in the version history.
  • Extraire (Extract) saves only the selection (repeats included) to a new file.

In the car and with the screen off

The player goes through the phone's built-in player: lock screen, control center and CarPlay all work, and "previous / next track" jumps from block to block. Loops and a changed tempo keep going with the screen off. After an interruption (GPS, call), playback resumes by itself. The count-in, metronome, takes and trainer are less reliable in CarPlay. The latest mixes and tempos can be replayed offline.

Recording and editing audio

Making a new recording

  1. In the destination folder: + › Record audio (or, with the app installed on Android, long-press the icon › Record audio).
  2. Allow the microphone if the phone asks. The sound is captured raw: no noise reduction, no automatic gain.
  3. Tap the big red button. The waveform draws itself live; "SAT" lights up if the signal clips (move the mic further away).
  4. Tap the red button again to stop. The app preselects the part you played (without the talking at the start and end) and normalizes the level: tap Garder (Keep) to keep only the music.
  5. Listen, touch it up if needed (tools below), then tap Enregistrer (Save) (floppy disk).
  6. Enter a Titre (Title) (the file will be called "YYYYMMDD Title.m4a"), then:
    • Envoyer maintenant (Send now): sends it to the server and converts it to m4a;
    • Garder sur le téléphone (Keep on the phone): perfect at a rehearsal with no network. A banner "N take(s) to send" shows up in the file list; tap Send all later.
💡

A take leaves the phone lossless (FLAC), and the upload picks up again by itself after a dropout, when you reopen the app or when the network comes back. A take is only erased from the phone once it has reached the server. Tapping the red button again replaces the previous take.

⚠️

Don't switch apps during a take: the recording stops (what was already recorded is kept). An incoming call stops it too. A take is limited to 90 minutes. You need the https address (invitation link) and Safari (iPhone) or Chrome (Android). Microphone blocked on iPhone: "aA" in the address bar › Website Settings › Microphone › Allow.

Recording to a click (metronome)

Recording over real drums

In the recorder's Métronome (Metronome) window, the Son (Sound) is a real drum kit recorded in a studio by default (the Clic (Click) is still an option): a kit suited to each style, several dynamics and alternating hits for a human feel. Each style offers ten patterns, so a hundred reference grooves (Motown, one drop, rockers and steppers, real bossa clave, jazz ride, Texas shuffle, train beat…), each at its usual tempo.

  1. Open the recorder (+ › Record audio), tap the metronome button and turn it on: drums are the suggested sound.
  2. Choose the style (Rock, Pop, Ballade, Funk, Disco, Hip-hop, Reggae, Bossa nova, Jazz with the Jazz aux balais (Jazz with brushes) option, Blues shuffle; Valse (Waltz) in 3/4, 6/8), then the pattern. Tapping a style or a pattern plays it right away, on a loop; changing the tempo or pattern while listening restarts it. Set the volume.
  3. Plug in headphones: the drums are then not recorded, only your instrument is.
  4. Tap the red button: a stick count-in, then the drums play while you record. Just like with the click, the take is aligned to the grid.

A style's kit downloads the first time (5 to 8 MB), then stays on the phone. Sound credits, shown in the app: DRSKit (DrumGizmo.org, CC BY 4.0), Virtuosity Drums (Versilian Studios), Big Rusty Drums (Karoryfer Samples).

The take split into cycles

After the take, the server finds the cycles, just like in the advanced player, and shows them as numbered blocks above the waveform ("Recherche des tournes…" (Finding cycles…) while it works; tap the message to try again if it fails).

  • Tapping a block plays it on a loop; tapping other blocks extends the selection.
  • Adjusting a boundary: the top handle snaps to bars (a little "click" at each bar, with a bubble "4 mes. │ 4 mes." (4 bars │ 4 bars)), or the round bottom handle for fine-tuning (the boundary moves half as much as your finger). When zoomed out, handles that are too close together are hidden: zoom in.
  • Boucler (Loop): loops the selection, or the whole take if nothing is selected, with no gap; after Garder (Keep), the loop keeps going over what you kept.

Perfect for a quick demo: find the good part, loop it, keep only what you need.

The editing tools

Select: press a little longer on the waveform, then drag (with a mouse: just drag); pull the handles to adjust. Zoom: pinch; double-tap to show everything.

Aligning to the grid

So that a recording dropped at the start of a music program, at the same tempo, lands right on the grid.

  1. After a take with the metronome, the Caler la prise sur les mesures ? (Align the take to the bars?) window opens by itself; otherwise, tap Caler (Align). It sums up in one sentence what will be done: tempo, time signature, number of bars.
  2. Tap Écouter le début (Listen to the start) to check the beginning.
  3. Oui, caler (Yes, align) trims the start and end on bar lines (the "1" is found from the kick and snare, and silence is added if needed); Non, garder telle quelle (No, keep it as is) leaves the take untouched.
  4. The fine settings are folded away: tempo (left empty, it is measured), time signature, shifting the start by one beat or one bar.

The ruler then switches to numbered bars, and the grid goes along with the file for its analysis. A take with no rhythm, one that's too short (less than 4 s of music) or one played without a click with a drifting tempo is refused, with an explanation.

Editing an existing file

  1. ⋯ menu of an audio file › Edit the audio (or swipe the row › Edit). Formats: wav, m4a, mp3, aif, aiff, flac.
  2. Trim, add your fades, normalize (same tools as above; plus Écouter la sélection (Play the selection) and Boucle sur la sélection (Loop the selection)).
  3. Save. For an m4a or a WAV, Enregistrer (Save) creates a new version of the same file (the old one stays in the history); Enregistrer comme nouveau fichier (Save as a new file) creates "Name (edited)". An mp3, aif or flac gives you a copy in .m4a.

Only the list of changes goes to the server, which rebuilds the file from the original, with no loss of quality. If someone changed or locked the file in the meantime, the app offers to save it as a new file.

Converting to WAV

⋯ menu › Convert to WAV…: Bit depth 16, 24 (default) or 32-bit float, Sample rate 44.1, 48 (default), 88.2 or 96 kHz, then Convert. A new .wav file is created in the same folder, from the original; the original does not change.

To Studio One and Cubase

Turns a song into a ready-to-open Studio One project, with the instruments split onto colored tracks and, optionally, a steadied tempo so the grid fits from start to end, even on a rehearsal played without a click.

Tap Create. Result: a "Song" folder (never overwritten: "Song 2"… if the name already exists) containing Song.song and a Media folder: "Vocals", "Guitars", "Bass", "Drums" (fixed colors), the takes, and "Mix" at the bottom, muted. All in 24-bit / 48 kHz WAV that carry their tempo. The project opens with the loop over the whole song and the windows tidied up.

On a band member's PC, the folder shows up in 28JoursBox: just open Song.song. The project then locks automatically for the other members. The project is always in 4/4.

To Cubase

Same idea for Cubase: the song's ⋯ menu › To Cubase… creates a project ready to open in Cubase 14 or later: a "Song Cubase" folder with the .cpr file and an Audio folder, one track per instrument, the takes as an option, and the tempo and sample rate (48 kHz) set. When opened in Cubase from the 28JoursBox folder, the project also locks automatically for the other members.

Step by step: everyday uses

From rehearsal to a rearranged song

The whole journey, with no computer in the rehearsal room.

  1. At rehearsal: + › Record audio, red button, play, red button. Tap Garder (Keep) to keep only the part you played, trim and add fades if needed (details). To play over a groove instead of a click: Clic (Click) › Son (Sound) › Batterie (Drums) (details). The take arrives already split into cycles: tap a block to loop it (details).
  2. No network? Save the take with Garder sur le téléphone (Keep on the phone). Once you're back on the network, tap Send all in the banner of the file list. The take leaves lossless (FLAC) and picks up again by itself after a dropout; it arrives as m4a in the chosen folder.
  3. Let the server do the work: a few seconds after it arrives, the song has its tempo, bars, sections, A/B/C cycles and chords. Overnight, it is separated into vocals, guitars, bass and drums, then the fine analysis names the sections (details).
  4. Open it in the advanced player and rework the arrangement: long-press then drag to move a block or a section, Dupliquer (Duplicate), Effacer (Erase), Garder, Nommer (Name) (Intro, Verse, Chorus…), Répéter (Repeat) a loop ×N, Extraire (Extract) a selection. Annuler (Undo) takes back anything (details).
  5. Keep the result: Enregistrer (Save) at the top creates "Title (edit)" for the whole band (details).
  6. Add your part: headphones plugged in, the ⏺ button in the advanced player; the take is aligned with the music and shared with the band (details).
  7. Everyone's own version, then the music program: each member can suggest their own structure by saving their edit; the others listen to it in the band's folder. Once it's decided, ⋯ menu › To Studio One… (or To Cubase…) creates the project with the separated tracks, or take the WAV (Convert to WAV…) for any music program (details).
👥

Fixing the split (boundaries, names, letters) benefits the whole band; rearranging (moving, erasing, copying) stays personal until you save the edit.

Learning a song before rehearsal

  1. Open the song in the Advanced player.
  2. Find the structure on the sections strip and the chords on the row above it.
  3. Tap TON (Key) for the scale and the pentatonic, Accords (Chords) for the chord diagrams.
  4. Double-tap a block to select its section, then ▶: it plays on a loop.

Working on a hard passage, slowly

  1. Select the passage (tap a block, pull the handles).
  2. Hold BPM and slide down, or tap BPM › 75% › OK.
  3. Optional: Outils (Tools) › Décompte d'une mesure (One-bar count-in) and Métronome (Metronome).
  4. Once you've got it: Outils › Entraîneur de tempo (Tempo trainer), from 80% up to the original tempo, in steps of +2.

Muting your instrument and playing along

  1. Pistes (Tracks); if needed, Séparer (Separate) and wait.
  2. M on your instrument (for example Basse, the bass), or lower its slider.
  3. OK, wait for "Mélange en service" (Mix in use), and play along with the band.

Recording your part over the song

  1. Original tempo and key, mic delay measured once, headphones plugged in.
  2. Optional: select a passage with Boucle (Loop) for one take per passage.
  3. ⏺, play, ⏺ to stop. The take is in Pistes (Tracks) and in the song's folder, for the whole band.

The drummer records to a click, then into the music program

  1. + › Record audio › Clic (Click): Activé (On), tempo, time signature, 1-bar count-in. With your own click in your headphones: Clic silencieux (Silent click). OK.
  2. Red button: count-in 1, 2, 3, 4, then the take starts on the 1. Red button to stop.
  3. Caler la prise sur les mesures ? (Align the take to the bars?): Écouter le début (Listen to the start), then Oui, caler (Yes, align).
  4. Save and send. On the PC, drag the file to the very start of a project at the same tempo: the hits land on the grid. Or use To Studio One….

Cleaning up a rehearsal recording

  1. ⋯ menu › Edit the audio.
  2. Select the chatter and Effacer (Erase), or select the song you played and Garder (Keep).
  3. A short Fondu entrée (Fade in) and Fondu sortie (Fade out) at the ends, then Normaliser (Normalize) with nothing selected.
  4. Save: a new version, and the original stays in the history.

Trying a new arrangement

  1. In the advanced player: long-press a block and drag to move it, drag up to erase it, Copier (Copy) / Coller (Paste), Dupliquer (Duplicate), Répéter (Repeat) ×2.
  2. Listen on a loop, Annuler (Undo) if needed.
  3. Enregistrer (Save) at the top: a new file "Title (edit)" for the band.

Fixing the split for the whole band

  1. If the badge is red: badge › Utiliser l'analyse fine (Use the fine analysis) › Appliquer (Apply).
  2. Adjust the boundaries (top handle snaps to bars, round bottom handle for fine-tuning), Découper (Split) / Fusionner (Merge), Nommer (Name) the sections, long-press the sections strip for the letters. If the rehearsal starts with a count-in, drag the purple "1" handle to the first real beat.
  3. Fix the key if needed: TON (Key) › Tonalité originale (Original key).
  4. Don't rearrange at the same time (moving, copying, erasing): the split would become personal. To undo everything: Outils (Tools) › Réinitialiser… (Reset…) › Revenir à l'analyse (Back to the analysis).

Going from a rehearsal to the studio

  1. The song's ⋯ menu › To Studio One….
  2. Check Recaler sur ce tempo… (Align to this tempo…) if the rehearsal was played without a click, and Une piste par instrument (One track per instrument).
  3. Create, then on the PC open Song.song in the 28JoursBox folder. With Cubase, pick To Cubase… and open the .cpr file.

Sharing photos and videos from a gig

  1. In the band's folder, + › New folder, for example "Gig 2026-10-12".
  2. Open it, then + › Upload new photos and choose photos and videos from the gallery (the app reminds you of the date of your last upload). During the gig, Take a photo or a video sends what you shoot straight away.
  3. The upload picks up again by itself after a network dropout. The other members see the thumbnails right away and open photos and videos full screen; they also arrive in the 28JoursBox folder on their PC.
  4. For the venue or the fans: the folder's ⋯ menu › Share a link (password and end date optional). To grab everything at once: Download (zip), up to 500 MB.

iPhone HEIC photos display in Safari; in other browsers, the preview may not be available (the file can still be downloaded). For large video files, make sure there's room on the server's disk (see the system requirements).

Trash and version history

The trash

  • Everything deleted (from a PC, a phone or the web) stays in the server's trash for 30 days. A file moved to the trash from the app shows a message with Undo.
  • Opening the trash: Settings › Open the trash (on a PC: left-hand menu). Each item shows who deleted it, when, and from where.
  • Restore: the item goes back to where it was (or to the root if its folder no longer exists; "(restored)" if the name is taken). Anyone can restore.
  • admin Delete for good an item, or Empty the trash (two confirmations).

Version history

⋯ menu of a file › Version history: each version with its date, size, the member and the PC. Buttons Listen, Preview, Download, Restore (the chosen version becomes the current one again; the current one stays in the history). Old versions are kept for 30 days; the current version, always.

Managing the server

🛠️

This chapter is for the person who looks after the server PC.

Managing from a phone or another PC

The group password (the one in the invitation link) does not give administration rights, except on the server PC. To manage things from anywhere else (trash, members, group name and logo, direct access, sending mail…), you need an administrator password.

  1. Once, on the server PC: Settings › Administration, set the administrator password (asked twice; Show password to see what you're typing).
  2. On the phone or the other PC: Settings › Administration › Unlock, enter that password. The app reloads with administration rights.
  3. The unlock lasts 12 hours. Lock again on this device ends it sooner (do this on a borrowed or shared device).

A wrong password shows "Mot de passe administrateur incorrect" (Wrong administrator password).

Changing the group password

Do this if the invitation link has gotten out of the group. Only on the server PC: Préférences (Preferences) › Serveur (Server) › Changer le mot de passe du groupe… (Change the group password…). All devices are signed out and all locks are released. Then send the new link to each member: on a PC, they just click Entrer le nouveau mot de passe (Enter the new password) in the panel and paste the link; on a phone, they just open the new link.

What the server does on its own

  • All the time: heavy processing is capped so the server stays reachable (analysis, chords and alignment on 3 cores max, instrument separation on 6, only one song or one transcription at a time).
  • At night (1 a.m. – 7 a.m.): for each m4a song, newest to oldest, one at a time: analysis, chords, instrument separation, detailed analysis. Then the previews of Office documents (if LibreOffice is installed). WAV and MP3 files are analyzed on demand. Track progress in Settings › Server status.
  • Every hour: clears out the trash and versions older than 30 days.
  • Every day: backup copy of the database (7 kept), update of the YouTube import tool, cleanup of mixes nobody has played in 30 days.
  • Every week (between 7 and 10 a.m.): full check of file integrity.

Backing up

The server backs up its database every day, but not your files to another drive. Regularly copy the data folder (Préférences (Preferences) › Serveur (Server) › Ouvrir le dossier des données (Open the data folder)), at least backups and blobs, to an external drive or a NAS. For example, in a Command Prompt:

robocopy D:\28JoursBox-Serveur E:\Sauvegarde /MIR /XD tmp uploads

Useful commands

In a Command Prompt run as administrator, in C:\Program Files\28JoursBox:

  • 28JoursBox.exe move-server-data --to E:\28JoursBox-Serveur: move the data to a bigger drive. The service is stopped, everything is copied and checked, then it restarts. The old folder is only renamed (".ancien"): delete it once you've checked the server.
  • 28JoursBox.exe import-folder --from D:\AncienDossier: bring a folder from the server's drive into the group (to switch from another sync software without re-uploading everything from a PC). Folder structure and dates are kept; --move avoids copying when it's on the same drive. If it's interrupted, run it again and it picks up where it left off.
  • 28JoursBox.exe fsck: check the integrity of the storage ("Intégrité OK.").
